# Task Manager Mobile Application

## Description
This is a mobile application developed using React Native to manage daily tasks efficiently.

## Features
- Add tasks
- Mark tasks as completed
- Delete tasks
- Day-wise task management
- View other days tasks

## Technologies Used
- React Native
- JavaScript

## How to Run
1. Clone the repository
2. Run `npm install`
3. Run `npx react-native run-android`
